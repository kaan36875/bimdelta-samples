# BIMDelta samples

IFC models under version control, with pull requests reviewed by
[BIMDelta](https://github.com/kaan36875/BIMDelta). Open any pull request to see the bot's
comment: what changed per class and storey, the quantity changes, the changed elements, and a
**View 3D diff** link.

| Path | |
|---|---|
| `models/house.ifc` | A two-storey house, stored as a normal Git file |
| `lfs/house.ifc` | The same house, stored with Git LFS |

The models are generated by
[`scripts/make_sample_building.py`](https://github.com/kaan36875/BIMDelta/blob/main/scripts/make_sample_building.py)
in the BIMDelta repository, so they can be shared freely.

## Parallel edits

Pull requests #5 and #6 both start from `main` and both touch the entrance. Before merging
either, check them against each other:

```text
$ bimdelta conflict wip/entrance-fire wip/entrance-layout -f markdown
```

| | Element | Fields | wip/entrance-fire | wip/entrance-layout |
|---|---|---|---|---|
| **conflict** | IfcDoor Front door | Pset_DoorCommon.FireRating | FireRating: EI30 → EI60 | FireRating: EI30 → EI90, moved |
| warning | IfcWall Exterior wall South L1 | different fields | FireRating: REI60 → REI90 | ThermalTransmittance: 0.28 → 0.22 |

The door's fire rating was changed to two different values: someone has to decide. The south
wall was changed in different properties, which combine, but is worth a look.

## Revisions

The repository follows the [ISO 19650 mapping](https://github.com/kaan36875/BIMDelta/blob/main/docs/iso-19650-mapping.md)
in the BIMDelta docs: branches are work in progress, pull requests are the check-review-approve
step into `main` (shared), and tags are published revisions. Tag
[`P01`](https://github.com/kaan36875/bimdelta-samples/releases/tag/P01) is the first published
revision of the house.

## Try it

1. Fork or clone this repository.
2. Change a model in any IFC authoring tool, or generate the second revision:

   ```bash
   pip install bimdelta
   curl -O https://raw.githubusercontent.com/kaan36875/BIMDelta/main/scripts/make_sample_building.py
   python make_sample_building.py models/house.ifc --revision B
   ```

3. Open a pull request. The workflow in `.github/workflows/bimdelta.yml` posts the review.

Locally, `bimdelta install-git-driver` makes `git diff` show element changes for these files,
`bimdelta serve` opens the history in the 3D viewer, and
`bimdelta quantities P01:models/house.ifc HEAD:models/house.ifc` compares the take-off with the
published revision.
