# BIMDelta samples

IFC models under version control, with pull requests reviewed by
[BIMDelta](https://github.com/kaan36875/BIMDelta). Open any pull request to see the bot's
comment: what changed per class and storey, the changed elements, and a **View 3D diff** link.

| Path | |
|---|---|
| `models/house.ifc` | A two-storey house, stored as a normal Git file |
| `lfs/house.ifc` | The same house, stored with Git LFS |

The models are generated by
[`scripts/make_sample_building.py`](https://github.com/kaan36875/BIMDelta/blob/main/scripts/make_sample_building.py)
in the BIMDelta repository, so they can be shared freely.

## Try it

1. Fork or clone this repository.
2. Change a model in any IFC authoring tool, or generate the second revision:

   ```bash
   pip install bimdelta
   curl -O https://raw.githubusercontent.com/kaan36875/BIMDelta/main/scripts/make_sample_building.py
   python make_sample_building.py models/house.ifc --revision B
   ```

3. Open a pull request. The workflow in `.github/workflows/bimdelta.yml` posts the review.

Locally, `bimdelta install-git-driver` makes `git diff` show element changes for these files.
